Tabs & Functionality

Providers Tab

Manage the provider roster. Add/remove physicians, PAs, and Mohs surgeons. Each provider is assigned a unique color for easy identification across the application.

My Schedule Tab

Providers set their own weekly pattern independently. Each day can be split into AM and PM blocks, with configurable type (Clinic/Surgery), location, hours, staffing needs, and optional skill requirements.

Medical Assistants Tab

Maintain the MA pool. Configure skills, preferred provider/location, and weekly availability. Availability hours are hard constraintsâ€”MAs outside those hours won't be suggested.

Weekly Schedule Tab

Automatically generated MA suggestions with manual override. Color-coded by provider, flags under-staffed blocks, supports one-click assignment/removal.

Year Calendar Tab

Month-by-month overview with visual indicators for each provider's schedule and time off. Click any day to jump to that week's detailed schedule.

Smart Assignment Algorithm

The system prioritizes blocks by difficulty (skill requirements first, then headcount), matches MAs to skills, respects availability constraints, and flags any gaps or conflicts.

Key behaviors:

  • Fills skill minimum first (e.g., "2 surgery-trained MAs")
  • Prefers MAs with soft preferences (provider/location match)
  • Never double-books same MA in same block
  • Allows same MA to work AM and PM same day
  • Clear warnings for under-staffed blocks or unmet skill requirements
